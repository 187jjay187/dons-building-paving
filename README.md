# Don's Building, Paving & Installations

Static client demo adapted from the KGM Paving website. Don's supplied project photography and videos are used throughout; the original hero montage is retained as requested.

Open index.html or serve this folder with a static web server. No build step is required. Contact forms prepare a WhatsApp message addressed to Don at +27 83 523 1697; the visitor sends it in WhatsApp.

The original extracted logo and a light version for dark backgrounds are in images/. The project sequence includes gallery arrows, slide selection, pause/play, keyboard navigation and touch swiping.
